# CommunityLab — Motor Inteligente de Transformação e Distribuição

Solução completa desenvolvida para o **Hackathon ONE Grupo 10 (Oracle Next Education & Alura)**.

## Como Rodar
1. Instale as dependências: `pip install -r requirements.txt`
2. Renomeie `.env.example` para `.env` e adicione sua `GEMINI_API_KEY`
3. Execute a interface: `streamlit run app.py`
